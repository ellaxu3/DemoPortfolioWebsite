# My Portfolio (Mockup)

A static, multi-page portfolio website built with HTML and CSS.

> **Disclaimer:** This is a **mockup website** created for coursework. The name "Ella Xu" is used as a **decoy**. It is placeholder content and does not represent a real person's professional portfolio.

## Overview

This project demonstrates the basic structure of a personal portfolio site, including a header, a navigation bar, a main content area with a headshot image and short introduction, and a footer.

## Pages

| Page | File | Description |
| --- | --- | --- |
| Home | `index.html` | Landing page with a welcome message, headshot, and short intro |
| Projects | `projects.html` | Projects page |

The navigation bar also includes **Professional Experience**, **Activities**, and **Education** links. These pages have not been built yet, so their links are placeholders.

## Project Structure

```
my-portfolio/
├── index.html        # Home page
├── projects.html     # Projects page
├── style.css         # Shared stylesheet
└── src/
    └── headshot.jpg  # Placeholder headshot image
```

## Built With

- HTML5 (semantic elements: `header`, `nav`, `main`, `footer`)
- CSS3

## Running Locally

1. Clone or download this repository.
2. Open the `my-portfolio` folder.
3. Open `index.html` in any web browser.

If you use VS Code, you can also right-click `index.html` and choose **Open with Live Server** to see changes update as you edit.
